# AI Trade Pro — نسخه پایه 0.1

این پوشه سورس اولیه یک اپلیکیشن Flutter اندروید است. هدف نسخه اول:
- پشتیبانی معماری از بازار نوبیتکس و بازار جهانی
- حالت پیشنهاد سیگنال و حالت خودکار (فعلاً قفل‌شده تا پایان آزمون)
- تحلیل چندعاملی قابل توضیح
- مدیریت ریسک و کیف پول آزمایشی
- اجرای موتور اصلی روی خود گوشی

## وضعیت فعلی
این یک اسکلت اجرایی اولیه است، نه نسخه نهایی و نه ربات آماده معامله. اتصال زنده API هنوز اضافه نشده؛ بنابراین برنامه عمداً قیمت و سیگنال ساختگی نشان نمی‌دهد. سفارش واقعی و ورود کلید API نیز وجود ندارد.

## پیش‌نیاز ساخت APK
1. نصب Flutter SDK و Android Studio روی ویندوز
2. باز کردن پوشه پروژه در Android Studio یا ترمینال
3. اجرای:
   ```bash
   flutter doctor
   flutter pub get
   flutter run
   ```
4. برای ساخت APK:
   ```bash
   flutter build apk --release
   ```
   خروجی معمولاً در `build/app/outputs/flutter-apk/app-release.apk` قرار می‌گیرد.

## مرحله‌های بعدی توسعه
1. افزودن سرویس دریافت داده عمومی و کندل با مدیریت خطا، محدودیت نرخ و زمان آخرین به‌روزرسانی.
2. افزودن ذخیره‌سازی محلی امن برای تنظیمات و دیتابیس معاملات کاغذی.
3. پیاده‌سازی بک‌تست، کارمزد، لغزش قیمت و گزارش عملکرد.
4. افزودن سرویس پس‌زمینه اندروید و اعلان دائمی؛ با توضیح محدودیت‌های بهینه‌سازی باتری.
5. پس از آزمون و تأیید کاربر، طراحی اتصال معاملاتی با API محدود و بدون مجوز برداشت.

## اصول ایمنی
- کلید API نباید در سورس کد یا فایل‌های قابل انتشار قرار گیرد.
- برای اتصال واقعی، مجوز برداشت باید غیرفعال باشد.
- ابتدا بک‌تست و Paper Trading؛ سپس فقط با تأیید صریح کاربر معامله واقعی.
- خروجی موتور تحلیل توصیه قطعی سرمایه‌گذاری نیست.
